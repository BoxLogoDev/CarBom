# 카봄 (CarBom)

하차 순간의 확인을 차량이 먼저 챙기는 가족 동승 케어 앱입니다.
현대자동차그룹 차량용 앱 개발 공모전 출품작으로, 뒷좌석에 아이·반려동물·부모님이 남아 있는 상황을 차량 신호로 감지해 운전자에게 단계적으로 안내하는 것을 목표로 합니다.

## 설계 원칙

- 코어 엔진은 플랫폼 독립적입니다. 엔진은 신호가 어디서 오는지 모릅니다 — 시뮬레이션 신호원에서 실제 차량 SDK로 신호원을 교체해도 세션 판정 로직은 그대로 유지됩니다.
- 판정은 결정적으로 동작합니다. 같은 신호 흐름에는 항상 같은 상태 전이와 같은 안내가 나옵니다.

없어 상태 변경은 없음). `poll_snapshot`(단일 어댑터 단건 읽기)의 다중 어댑터 버전이며 `poll_paired_into_sessions`(어댑터마다 1회 poll해 세션에 적용)의 읽기 전용 flat 버전이고, `poll_snapshots_for_adapters(adapters, 1)`이 어댑터당 1개짜리 tuple들의 tuple을 돌려주는 것과 다릅니다. 다중 어댑터 단건 적용 헬퍼 `poll_once_per_adapter_into_session(adapters, session)`는 adapters를 먼저 tuple로 구체화하고, 빈 입력이면 어떤 어댑터도 poll하지 않고 세션을 변경하지 않은 채 현재 상태를 돌려주며, 비어 있지 않으면 적용 전에 기존 `poll_snapshots_once_per_adapter`로 각 어댑터를 정확히 1회 poll해 스냅샷들을 모두 먼저 모은 뒤 입력 순서대로 세션 하나에 적용하고 최종 `SessionState`를 돌려주고, 중복 어댑터는 등장할 때마다 따로 poll하며, 수집 중 어느 어댑터라도 미연결이면 그 poll의 `NotImplementedError`가 전파되고 어떤 스냅샷도 적용되지 않아 세션은 변경되지 않으며, `poll_snapshots_once_per_adapter`(읽기 전용 flat 버전)의 적용 쪽 짝이며 `poll_paired_into_sessions`(어댑터-세션 짝 적용)와 다릅니다. 다중 세션 단건 방송 헬퍼 `poll_once_per_adapter_into_sessions(adapters, sessions)`는 adapters와 sessions를 먼저 각각 tuple로 구체화하고, sessions가 비어 있으면 어떤 어댑터도 poll하지 않고 빈 tuple을 돌려주며, adapters가 비어 있으면 poll 없이 각 세션의 현재 상태를 입력 순서대로 돌려주고 세션은 변경되지 않으며, 둘 다 비어 있지 않으면 적용 전에 기존 `poll_snapshots_once_per_adapter`로 각 어댑터를 정확히 1회씩 poll해 스냅샷들을 모두 먼저 모은 뒤 그 시퀀스 전체를 각 세션에 `apply_snapshots`로 적용하고 최종 상태들을 sessions 입력 순서의 tuple로 돌려주며, 중복 어댑터는 등장할 때마다 따로 poll하고 중복 세션은 그대로 유지하며, 수집 중 어느 어댑터라도 미연결이면 그 poll의 `NotImplementedError`가 전파돼 어떤 세션도 변경되지 않습니다. `poll_once_per_adapter_into_session`(여러 어댑터를 세션 하나에 적용)의 다중 세션 방송 버전이며 `poll_paired_into_sessions`(어댑터-세션 1:1 짝 적용)와 다르고 `poll_into_sessions`(스냅샷 1건을 여러 세션에 적용)의 다중 어댑터 버전입니다. 다중 어댑터 균일 반복 단일 세션 적용 헬퍼 `poll_repeatedly_for_adapters_into_session(adapters, session, times)`는 times가 음수이면 adapters가 비어 있어도·미연결 어댑터가 있어도 가장 먼저 `ValueError`를 내며 poll·세션 변경이 없고, adapters를 먼저 tuple로 구체화하며, adapters가 비어 있거나 times가 0이면 어떤 어댑터도 poll하지 않고 세션 현재 상태를 그대로 돌려주므로 미연결 어댑터에서도 예외가 나지 않고, 그 외에는 `poll_snapshots_for_adapters`로 어댑터별 슬라이스를 모두 먼저 모은 뒤 어댑터 순서대로 flatten해 세션 하나에 순서대로 적용하고 최종 상태를 돌려주며, 중복 어댑터는 등장할 때마다 따로 poll하고, 수집 중 어느 어댑터라도 미연결이면 `NotImplementedError`가 전파돼 세션은 변경되지 않습니다(앞선 어댑터들의 poll은 이미 일어났을 수 있음). `poll_snapshots_for_adapters`(균일 횟수 읽기)의 적용 쪽 짝이며 `poll_once_per_adapter_into_session`(어댑터마다 1회)의 반복 버전이고, `poll_repeatedly_for_adapters_into_sessions`(어댑터-세션 짝 적용)와 달리 모든 어댑터의 스냅샷이 세션 하나에 이어서 적용됩니다. 짝 횟수 다중 어댑터 단일 세션 적용 헬퍼 `poll_repeatedly_paired_into_session(adapters, session, times_list)`는 adapters와 times_list를 먼저 각각 tuple로 구체화하고 길이가 다르면 `ValueError`를 내며 어떤 어댑터도 poll하지 않고 세션은 변경되지 않고, 길이는 같지만 어느 times라도 음수이면 `ValueError`를 내며 poll·세션 변경이 없고(길이 검사 다음에 적용, 미연결 어댑터에서도 먼저 적용), adapters가 비어 있거나 모든 times가 0이면 어떤 어댑터도 poll하지 않고 세션 현재 상태를 그대로 돌려주므로 미연결 어댑터에서도 예외가 나지 않으며, 그 외에는 기존 `poll_snapshots_paired`로 어댑터별 슬라이스를 모두 먼저 모은 뒤 어댑터 순서대로 flatten한 시퀀스 전체를 세션 하나에 순서대로 적용하고 최종 `SessionState`를 돌려주고, 중복 어댑터는 등장할 때마다 따로 poll하며, 수집 중 어느 어댑터라도 미연결이면 그 poll의 `NotImplementedError`가 전파돼 어떤 스냅샷도 적용되지 않아 세션은 변경되지 않습니다(앞선 어댑터들의 poll은 이미 일어났을 수 있음). `poll_snapshots_paired`(읽기 전용 짝 버전)의 적용 쪽 짝이며 `poll_repeatedly_paired_into_sessions`(어댑터-세션 짝 적용)의 단일 세션 버전이고 `poll_repeatedly_for_adapters_into_session`(균일 횟수)의 짝 횟수 버전입니다 |

## 시연 데모 (`demo/`)

차량 화면과 운전자 폰 화면을 나란히 재현하는 정적 웹 데모입니다. 차량 화면에는 세션 상태·안내 단계·안내 문구와 신호 지표 6종(뒷문·후석 벨트·시동·잠금·공조·실내 온도)을, 운전자 폰 화면에는 단계별 알림 카드를 표시합니다. 시나리오 3종(등원 정상 흐름, 하차 깜빡 + 온도 상승, 반려동물 등원)을 골라 '다음 단계'·'처음부터' 버튼으로 수동으로 진행하며 살펴볼 수 있습니다.
